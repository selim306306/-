# مساعد المكتبة المدرسية — دليل النشر

## 1) النشر على GitHub Pages (مجاناً)
1. أنشئ مستودعاً جديداً على GitHub (Public) وارفع كل ملفات هذا المجلد (index.html وsw.js وmanifest.webmanifest والأيقونات).
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/` — افتحه من الموبايل بـ Chrome.
4. أول فتح: اختر كلمة مرور، اسمح للكاميرا والميكروفون، وانتظر تحميل النماذج (مرة واحدة).
5. من قائمة Chrome ⋮ اختر «تثبيت التطبيق» — يظهر كأيقونة على الشاشة الرئيسية ويعمل بملء الشاشة.

## 2) تفعيل الذكاء الاصطناعي بأمان (Cloudflare Worker)
لا تضع مفتاح API داخل الصفحة على GitHub أبداً. استخدم الوسيط:
1. سجّل في cloudflare.com ← Workers & Pages ← Create ← Worker ← الصق محتوى `worker.js` ← Deploy.
2. Settings ← Variables:
   - `ANTHROPIC_API_KEY` (نوع Secret): مفتاحك من console.anthropic.com
   - `ALLOWED_ORIGIN`: `https://USERNAME.github.io` (بدون مسار وبدون / في النهاية)
   - `MODEL` (اختياري): مثال `claude-haiku-4-5-20251001`
3. انسخ رابط الـ Worker، ثم في التطبيق: الإدارة ← الإعدادات ← «المساعد الذكي» ← فعّل، الصق الرابط، اضغط «اختبار الاتصال».
4. اضبط حداً للإنفاق من لوحة Anthropic، وفعّل Rate Limiting على الـ Worker.

## 3) تحويله لتطبيق أندرويد (APK) — اختياري
ادخل على pwabuilder.com، الصق رابط GitHub Pages، واختر Android لتحصل على ملف يمكن تثبيته أو رفعه على المتجر.

## 4) بعد النشر
افتح الإدارة ← الإعدادات ← «فحص الأذونات والتشغيل» ← «ابدأ الفحص»، وتأكد أن كل البنود خضراء.
خذ نسخة احتياطية مشفّرة بانتظام (الإعدادات ← تصدير نسخة مشفّرة).

## 5) الذكاء الاصطناعي المجاني (Gemini)
1. افتح aistudio.google.com وسجّل بحساب جوجل ← Get API key ← Create API key.
2. قيّد المفتاح لـ Generative Language API فقط (من Google Cloud Console ← Credentials).
3. في التطبيق: الإدارة ← الإعدادات ← «المساعد الذكي» ← طريقة الاتصال «Gemini مجاني» ← الصق المفتاح ← حفظ ← اختبار الاتصال.
4. الحدود المجانية تظهر في لوحة AI Studio وتتغير، وفي الباقة المجانية قد تستخدم جوجل الأسئلة لتحسين منتجاتها.

## 6) الفهرسة والرقم العام (جديد)
- **الرقم العام** هو مفتاح كل نسخة: الإعارة والإرجاع والجرد والبطاقات والملصقات. لا يُقبل رقم مكرر. يقبل إدخال نطاق (مثال: 1666-1670).
- **إضافة كتاب:** الإدارة ← «إضافة كتاب». يدوياً، أو صوّر الغلاف (ملصق الرقم العام) وصفحة العنوان ثم «اقرأ البيانات من الصور» (يتطلب تفعيل المساعد الذكي). الحقول غير المؤكدة تظهر باللون الأحمر، وأنت تراجع كل شيء قبل الحفظ.
- **بطاقات الفهرسة:** ثلاث بطاقات لكل كتاب (مؤلف، عنوان، مصنف) بمقاس 12.5×7.5 سم. للطباعة على كروت مطبوعة مسبقاً اختر «النص فقط» و«مقاس البطاقة» واضبط الإزاحة بعد طباعة بطاقة اختبار.
- **ملصقات الباركود (Code 39)** بالرقم العام لكل نسخة.
- رقم ديوي المقترح من القراءة الآلية مجرد اقتراح، راجعه من جداولك.

## 7) لوحة التحكم (جديد)
لوحة التحكم، الحوكمة (الترويسة وأمر المدير للموافقة)، السجلات (جدول الحصص وسجل المترددين)، الجرد، والأقسام المخصصة (أنشطة، إهداءات، استبعاد، خطة سنوية، أو قسم تصمّمه بنفسك). كل التقارير تُطبع بترويسة المدرسة.
عند تحديث الملفات على GitHub افتح الرابط وأعد تحميله مرتين حتى يتحدّث التخزين المؤقت.

## 8) الأشخاص والوظائف وتسجيل الزائر الغريب (جديد)
- تبويب **الأشخاص**: كل شخص له وظيفة (طالب، معلم، إداري، مدير المدرسة، متابع، مدير الإدارة، زائر رسمي، زائر) وصيغة ترحيب. تعدّل الوظائف والصيغ من «الوظائف والترحيب»، وتضيف وظائف جديدة.
- **صور مرجعية:** من «شخص جديد ← رفع صور مرجعية» (3 إلى 5). يفحص البرنامج وجود وجه واحد واضح، ويخزّن أرقاماً مشفّرة لا الصورة. يُفضّل إضافة التقاط مباشر بالكاميرا أيضاً.
- **المسؤولون الرسميون** يُعرَّفون من لوحة الإدارة فقط. يُطلب لهم تطابق أعلى (4 لقطات متتالية) قبل الترحيب الرسمي، ويُعرض عليهم إحصائيات المكتبة، وتُسجَّل زيارتهم في «سجل الزيارات الرسمية» (تبويب السجلات).
- **الزائر غير المعروف:** يرحّب به المساعد ويسأله عن اسمه ووظيفته (طالب/معلم/زائر) وفصله، ويطلب موافقته على بصمة الوجه، ثم يلتقط 5 لقطات. يظهر ملفه في «الأشخاص ← بانتظار الاعتماد» بصورة مصغّرة لمطابقته. لا يستطيع الاستعارة قبل اعتمادك، ولا يمكنه تسجيل نفسه كمسؤول. يُعطَّل من «الحوكمة ← التسجيل الذاتي».
- عند اللبس بين شخصين متقاربين، لا يبدأ التسجيل الذاتي، بل يرحّب بصيغة محايدة.
